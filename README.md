# قیمت منصفانه (اپ اندروید)

اپ Capacitor که لینک آگهی دیوار را می‌گیرد (اشتراک‌گذاری از اپ دیوار یا چسباندن لینک) و گزارش قیمت/اجاره منصفانه با گیج نشان می‌دهد.
منطق محاسبه همان افزونه مرورگر است (`www/core.js`).

## ساخت APK
با هر push، GitHub Actions فایل `app-debug.apk` را می‌سازد (تب Actions → آخرین اجرا → Artifacts).

## ساختار
- `www/` صفحه اپ، داده‌ها و منطق
- `android-patch/` کلاس MainActivity (دریافت لینک اشتراکی) و اسکریپت افزودن intent-filterها
- `capacitor.config.json` — CapacitorHttp فعال است تا درخواست به api.divar.ir بدون محدودیت CORS انجام شود

## نسخه ۱۰: سه بخش
- **تحلیل لینک**: مثل قبل (همراه دکمه «ذخیره در علاقه‌مندی‌ها»).
- **تخمین دستی** (`www/tabs.js`): نوع/شهر/محله/متراژ/سال/طبقه/امکانات را وارد کنید؛ همان گزارش و گیج نمایش داده می‌شود. قیمت درخواستی اختیاری است.
- **علاقه‌مندی‌ها**: ذخیره مشخصات و قیمت آگهی در حافظه گوشی (localStorage)، ثبت تاریخچه تغییر قیمت با «بروزرسانی»، نگهداری آخرین اطلاعات آگهی حذف‌شده، و مقایسه دو آگهی.
- منطق محاسبه (`core.js`, `app.js`) تغییر نکرده است.

## نسخه ۱۱: تخمین دستی
- جست‌وجو در لیست شهر و محله (فیلتر هنگام تایپ).
- کیفیت ملک در محله (۵ سطح) × کوچه (۳ سطح) = ۱۵ حالت؛ ضریب هر حالت از پراکندگی واقعی قیمت همان محله (چارک‌های lo/hi) به‌دست می‌آید و جدول آن با توضیح روش در خود اپ هست.
- زیرمحله‌های دلخواه (مثلاً جمالزاده ← شمالی) با کیفیت و کوچه پیش‌فرض قابل ذخیره‌اند.
- تعداد پارکینگ در فرم تخمین دستی.
- فقط `www/tabs.js` و `www/index.html` تغییر کرده‌اند؛ `core.js` و `app.js` دست‌نخورده.
